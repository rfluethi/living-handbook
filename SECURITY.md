# Security Policy

## Supported versions

Living Handbook is in its 0.x series. Security fixes are made for the latest
0.x release only and shipped as a new release. Please update to the latest
release before reporting, and say which version you tested.

| Version          | Supported |
| ---------------- | --------- |
| latest 0.x       | yes       |
| older 0.x        | no        |

## Reporting a vulnerability

Please do not open a public issue for security problems.

The preferred way is GitHub's private vulnerability reporting:
[report a vulnerability](https://github.com/rfluethi/living-handbook/security/advisories/new)
on the repository's Security tab. The report stays private between you and the
maintainer, and the fix and the advisory can be prepared in the same place.

If you cannot use GitHub, email the maintainer at mail@rfluethi.com.

Include a description, steps to reproduce, the affected version, and the
WordPress and PHP versions if they matter.

## What to expect

- An acknowledgement within 7 days.
- An assessment and, where the report is confirmed, a plan for the fix. You
  will hear how it is going if the fix takes longer than a few weeks.
- A release with the fix, and credit in the release notes and the advisory
  unless you prefer not to be named.
