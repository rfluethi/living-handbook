# Technical documentation

For whoever installs, styles or extends the plugin: [German](de/README.md), [English](en/README.md).

The English folder is the one to start from, and the one with the images. Both ship inside the plugin and can be loaded into a WordPress site through **Handbook → Import → App handbook**, so a site can read them without leaving the admin.

The two are separate texts rather than a translation pipeline, which means a change to one is a change to both. `CONTRIBUTING.md` used to claim the German version was the source and the English one derived from it; that was never true and caused half of a day's documentation findings on 2026-08-05. Neither is the source now: both are.
