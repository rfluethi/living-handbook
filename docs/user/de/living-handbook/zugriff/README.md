# Zugriff

Dieser Bereich regelt die wichtigste Frage eines internen Handbuchs: Wer darf was lesen? Die erste Seite zeigt, wie du die Sichtbarkeit einstellst. Die zweite erklärt das Prinzip dahinter. Damit überrascht dich das Verhalten des Plugins nie. Die dritte zeigt, wie ein KI-Werkzeug dieselbe Regel einhält.
