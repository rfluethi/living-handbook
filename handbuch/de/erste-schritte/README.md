# Erste Schritte

Dieser Bereich führt von der Installation zur ersten eigenen Seite. Er ist ein Ordner mit einer `README.md`, darum siehst du hier diesen Einleitungstext. Die Seiten des Bereichs stehen links im Navigationsbaum.

Ein Bereich **ohne** eine solche `README.md` bekommt beim Import stattdessen automatisch eine Liste seiner Seiten als Karten. Der Bereich „Pflege" zeigt das.
