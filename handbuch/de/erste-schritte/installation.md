# Installation

So wird das Plugin einsatzbereit.

## Voraussetzungen

- WordPress 6.7 oder neuer, mit einem Block-Theme. Einstiegsseite, Einzelseite und Navigation werden aus Block-Templates gebaut, ein klassisches Theme rendert sie nicht.
- PHP 8.1 oder neuer.
- Eine Einzelinstallation. Auf einem Multisite-Netzwerk aktivierst du pro Seite.

## Aktivieren

1. Lade das Plugin unter **Plugins, Installieren, Plugin hochladen** hoch und aktiviere es.
2. Die Aktivierung legt eine Seite „Handbuch" mit dem Übersichts-Block an und zeigt einen Hinweis.
3. Erscheinen die Handbuch-URLs nicht sofort, öffne einmal **Einstellungen, Permalinks**.

## Danach

Lege dein erstes Handbuch an: [Erstes Handbuch anlegen](erstes-handbuch-anlegen.md).
