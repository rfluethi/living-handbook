# About this handbook

This is the user handbook for Living Handbook. It explains, step by step, how to work with the plugin. The handbook is itself built with Living Handbook. Everything you see here is produced by the plugin: the navigation on the left, the badges, the review data and the feedback prompt at the bottom.

## Who it is for

This handbook is for everyone who uses Living Handbook. You do not need any programming knowledge. If you have written a page in WordPress before, that is enough.

Do you develop the plugin itself? Then there is also the [developer documentation on GitHub](https://github.com/rfluethi/living-handbook/tree/main/docs). It describes the technical design and the code. This handbook links there wherever it helps.

## How it is structured

A website can run several handbooks with Living Handbook, for example a public user handbook next to an internal team handbook. Each handbook has its own pages, its own entry page and its own rule about who may read it. The handbook you are reading is one of them: the documentation of the plugin.

Every handbook is built the same way. It consists of **areas**, and each area contains **pages**. You see the areas as tiles on the handbook's entry page and as the main items in the navigation on the left.

Every handbook page is built from **blocks** and follows a **template**. Both can be adjusted, and that is where much of the freedom lies: through the blocks and their settings you decide what a page can do and show, through the templates and a few lines of CSS you decide how it looks. The [Interface](interface/README.md) area shows how.

## The most important terms

| Term | Meaning |
|---|---|
| **Handbook** | The container for pages that belong together. It controls who may read. A website can have several handbooks. |
| **Handbook page** | A single page inside a handbook. |
| **Area** | A top-level page with its subpages, for example "Getting started". |
| **Entry page** | The start page of one handbook, with search, filters and area tiles. |
| **Badges** | The small labels on every page: page type, topic, audience and review status. |
| **Review interval** | How long a review stays valid before the page is marked "Review due". |

## How to read it

You do not have to read everything. If you know WordPress well, the [Quick start](quick-start.md) on one page may be all you need. For everyone else, [Getting started](getting-started/README.md) is the right entry. Look everything else up when you need it. The search on the handbook's entry page finds every page.

You can also load this handbook into your own WordPress installation. One click loads it from the plugin, matching the installed version. The instructions: [Load the app handbook](getting-started/load-the-app-handbook.md).
