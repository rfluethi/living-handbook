# About this handbook

This is the handbook of the Living Handbook application, written as a Living Handbook. It explains how to use the plugin and is at the same time an example of what a handbook looks like.

It lives as ordinary Markdown files in a public GitHub repository and is loaded into an install through the **App handbook** tab on the import screen. Because it is a GitHub import, the pages stay in sync with the repository: a later change on GitHub reaches your site on the next load.

## How it is put together

A handbook is made of **areas**, and each area holds **pages**. In this repository an area is a folder and a page is a Markdown file. The folder structure becomes the page hierarchy on import.

Two areas follow as an example: "Getting started" and "Upkeep".

## What works in Markdown

Not every kind of markup survives the import. What belongs here and what does not is in [Getting started, Writing content](getting-started/writing-content.md).
