# Create your first handbook

A handbook is the container your pages live in.

## Create it

Go to **Handbook, Handbooks, Add New**, give it a name (for example "General") and a short description, and save.

Set its **visibility** on the same screen. A new handbook defaults to "All members (logged in)", so a logged-out visitor sees nothing until you set it to "Public" or grant roles and people. This is deliberate: the plugin is fail-closed, it would rather hide a page than leak it.

## First page

Go to **Handbook, Add New** and write the page like any block-editor page. Two things in the sidebar matter before you publish:

- **Assign the page to a handbook.** This is the step people miss. A page with no handbook stays invisible on the front end.
- **Classify the page.** Set the page type, topic, audience and responsible role. These drive the badges and the filters.
