# Installation

How to get the plugin ready to use.

## Requirements

- WordPress 6.7 or newer, with a block theme. The entry page, the single page and the navigation are built from block templates, so a classic theme will not render them.
- PHP 8.1 or newer.
- A single-site install. On a multisite network, activate it per site.

## Activate

1. Upload the plugin under **Plugins, Add New, Upload Plugin** and activate it.
2. Activation creates a page called "Handbook" with the overview block, and a notice points you to the next step.
3. If the handbook URLs do not appear right away, open **Settings, Permalinks** once.
