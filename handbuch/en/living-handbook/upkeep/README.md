# Upkeep

Most documentation tools help you publish. Living Handbook is built around what comes after: keeping pages correct once they exist. This area explains the review cycle, the day-to-day review work and the reader feedback.

Documentation without upkeep goes wrong. And wrong documentation is worse than none: people trust it until it fails.
