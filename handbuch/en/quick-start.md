# Quick start

The whole path to a finished handbook on one page. For everyone who knows WordPress well and just wants an overview. Every step links to the detailed guide.

## Six steps to a handbook

1. **Install:** Upload the plugin ZIP and activate it. Requirements: WordPress 6.7 with a block theme, PHP 8.1. Details: [Installation](getting-started/installation.md).
2. **Create a handbook:** Under **Handbook → Handbooks**, create a handbook and set its **visibility**. Careful: new handbooks start on "All members (logged in)", not on "Public". Details: [Create your first handbook](getting-started/create-your-first-handbook.md).
3. **Create pages:** Under **Handbook pages → Add new handbook page**, write as usual. Mandatory: **assign every page to a handbook**. A page without a handbook stays invisible on the website. Details: [Create your first page](getting-started/create-your-first-page.md).
4. **Classify:** For each page, pick the page type, topic, audience and responsible role. These produce the badges and the filters.
5. **Organise:** Set the parent page and the order under Page Attributes. That builds the navigation, with no menu upkeep. Details: [Organise pages](getting-started/organise-pages.md).
6. **Set review data:** In the **Handbook maintenance** box, enter the review date and the review interval. The plugin then shows on every page how current it is, and reports overdue reviews on the dashboard. Details: [The review cycle](upkeep/the-review-cycle.md).

## The one principle you need to know

When in doubt, the plugin hides. A page without a handbook is invisible. A new or imported handbook never starts public. If something does not show up, this is almost always why. Details: [Understanding access](access/understanding-access.md).

## The most important places in the admin

| Place | What you do there |
|---|---|
| **Handbook → Handbooks** | Create handbooks, control visibility. |
| **Handbook → Handbook pages** | Write, review and manage pages. |
| **Handbook → Import** | Bring in Markdown: pasted, as a ZIP, from GitHub or as a bundle. This handbook also loads here, on the [App handbook](getting-started/load-the-app-handbook.md) tab. |
| **Handbook → Export** | [Export](content/move-a-handbook.md) a handbook as a bundle for another website. |
| **Handbook → Settings** | [All options](the-settings.md): sync schedule, custom CSS, uninstall behaviour. |
| **Dashboard** | Keep an eye on overdue reviews and feedback numbers. |
